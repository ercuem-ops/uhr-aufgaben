Datenschutzerklärung für Uhr-Aufgaben

Stand: November 2026

Worum es geht

Uhr-Aufgaben ist eine private App für eine Wear-OS-Smartwatch. Sie zeigt Listen aus Google Tasks an und erlaubt, Einträge abzuhaken. Die App wird nur vom Betreiber selbst genutzt und nicht öffentlich angeboten.

Welche Daten die App verwendet

Nach der Anmeldung mit einem Google-Konto erhält die App über die Google Tasks API Zugriff auf die Aufgabenlisten dieses Kontos (Berechtigung https://www.googleapis.com/auth/tasks). Die App liest Listennamen und Aufgaben und ändert nur den Status „erledigt“ bzw. „offen“ einzelner Aufgaben.

Speicherung und Weitergabe

  • Die Daten werden direkt zwischen der Uhr und Google ausgetauscht.
  • Es gibt keinen eigenen Server. Daten werden nicht an Dritte weitergegeben.
  • Die App speichert keine Aufgaben dauerhaft auf der Uhr. Sie werden bei jedem Öffnen neu geladen.
  • Es gibt keine Werbung, keine Analyse- oder Tracking-Dienste.

Verwendung von Google-Nutzerdaten

Die Nutzung von Daten, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Zugriff widerrufen

Der Zugriff kann jederzeit unter myaccount.google.com/permissions entzogen werden. Danach kann die App keine Aufgaben mehr lesen oder ändern.
